# Основной каталог Cookly — «Рацион»

26 октября 2026. Пользователь подтвердил в чате получение разрешения на использование источника. Фото и полные инструкции включены в основной сценарий Cookly, без ограничения localhost и без preview-флага.

## Что работает

- `/catalog`: живой каталог на русском с фотографиями, поиском, фильтром приёма пищи и пагинацией. При проверке API и браузер показали **2080** рецептов; число берётся из ответа API.
- `/recipes`: подбор по исходным продуктам. Cookly ищет кандидатов по выбранному основному продукту, загружает состав максимум шести рецептов и ранжирует подтверждённые совпадения. Следующие кандидаты — по кнопке, без пропуска позиций; подтверждённые рецепты накапливаются и повторно ранжируются. При ошибке сначала нужен повтор загрузки.
- `/recipe/racion/:id`: фото, оригинальные ингредиенты, количества на выбранные 1–6 порций, КБЖУ на одну порцию и полные шаги внутри Cookly.
- `/cook/racion/:id`: крупные шаги, таймер, список ингредиентов, завершение и отзыв. При возврате сохраняются порции, фильтры каталога и набор сверки.
- Профильные ограничения проверяются по полному составу. Неизвестные ингредиенты не считаются имеющимися. Курица и филе, разные виды масла и другие разновидности не склеиваются при вводе продуктов.
- 48 локальных рецептов сохранены; они доступны и при ошибках внешнего сервиса. Исследовательские источники и их корпуса не включены в этот выпуск.

## Границы

Это живое подключение, **не локальная копия всех 2080 полных рецептов**. Подбор проверяет группы кандидатов, а не гарантирует поиск лучшего совпадения среди всего каталога. На один такой запрос приходится до 7 обращений API. Заявленные ограничения источника — 50 запросов/час и 300/сутки на IP; подтверждение разрешения не меняет техническую квоту автоматически.

Для экономии запросов используются общий ограниченный кеш в памяти на 10 минут, объединение одинаковых запросов и обработка 429/Retry-After. Ошибки не кешируются; отмена одного потребителя не мешает другому. Постоянного хранения или массовой выгрузки корпуса нет.

Сверяется наличие продуктов, не достаточность запасов. Единое правило для обоих источников: по умолчанию соль, вода, обычные растительные масла и явно перечисленные сухие специи исключены из счётчиков. Они остаются в полном составе и помечаются «Базовый продукт», без ложной записи в холодильник. Общий переключатель позволяет учитывать их как обычные продукты и сохраняется в браузере. Свежие овощи/зелень, сахар, сливочное масло и соусы базовыми не считаются. Количества и ингредиенты источника не переписываются. Уникальные продукты считаются по строгим идентификаторам или точному названию; один продукт в нескольких строках не увеличивает счётчик. Совпадений только по специям недостаточно для рекомендации. Количества ингредиентов источника указаны на одну порцию и пересчитываются; исходные числа в шагах, время и температура не переписываются. Недостающие значения не выдумываются. У каждого рецепта есть ссылка на оригинал «Рациона».

## Проверка и запуск

Результаты тестов, сборки и проверки браузера: `docs/racion-validation.json`. Публикуемый сайт: https://alikhan-35.github.io/cookly/#/catalog.

Для обычной сборки достаточно `npm run build`. Основной каталог включён без дополнительных флагов. GitHub Actions задаёт базовый путь `/cookly/` и берёт существующие параметры PostHog из repository variables.

Постоянный адрес: https://alikhan-35.github.io/cookly/#/catalog. Этот документ сопровождает выпуск для GitHub Pages; результат публикации подтверждается workflow Deploy Cookly to GitHub Pages.
