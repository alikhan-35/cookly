# Исправление пустой выдачи Cookly

29 октября 2026.

Причина: прежний подбор проверял только первые8 составов из4 поисков и останавливался. Ужесточённые фильтры отсеивали эту маленькую выборку, хотя в каталоге были подходящие блюда. Тесты ограничений запросов не проверяли реальный пользовательский результат.

Исправление: официальный нативный подбор источника /recipes?have=... ищет кандидатов по всему набору продуктов. Его HTML читается существующим сервером Cookly; API /api/recipes игнорирует have и для этого не используется. Cookly сам проверяет полные составы, не доверяя широким pantry-флагам источника. Автоматическая проверка продолжается до достаточного разнообразного набора или предела36 составов/60с. Основное мясо/рыба должны совпадать; совместимый вид/часть отмечается для уточнения, не превращается в точное наличие или автоматическое списание.

Проверка на 12 реально перечисленных пользователем позициях: Рис, Картофель, Яйца, Говядина, Баранина, Сёмга, Капуста, Мандарины, Масло сливочное, Сельдь, Сыр, Гречка. Живой запрос дал36 кандидатов, проверил16 составов и нашёл11 вариантов за3601мс, без ошибки. Примеры: гречка с маслом, рис с маслом, яйца с сыром, гречка с яйцом/зелёным луком, лосось с рисом/брокколи. Недостающие продукты и совместимые разновидности не скрываются. Рецепт с отсутствующим филе минтая исключён; добавлены регрессии для падежей рыбы/мяса.

Проверки: 655 тестов/28 файлов прошли. Реальные составы8 рецептов сохранены в тестовой фикстуре; есть автоматический проход дальше первых8 неудачных карточек, сохранение результатов при429, отмена, ограничения питания, базовые специи и совместимость. Прежний пятисекундный локальный тест однажды истёк на перегруженном хосте; окончательный общий прогон с запасом времени прошёл, CI проверяет стандартный запуск.
