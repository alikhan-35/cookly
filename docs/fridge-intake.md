# Добавление продуктов списком и голосом

Работает без серверного ключа: ввод русского списка, количества и единицы, диктовка через браузер, редактирование распознанных строк, подтверждение и атомарное сохранение. Неизвестные названия и неоднозначные количества требуют проверки. Дубли не увеличивают запасы и не перезаписывают уже сохранённые продукты.

«Разбор на устройстве» использует локальные правила и работает без серверного ключа. Отдельная кнопка «Разобрать с Gemini» отправляет список серверу; Gemini подключается к публичному Cookly в этом выпуске.

Голос запускается только кнопкой пользователя, заканчивается не позднее 45 секунд плюс ожидание финального фрагмента до 2 секунд. При уходе со страницы распознавание прерывается. Поддержка зависит от браузера; есть обычный текстовый ввод. Аудио может обрабатывать сервис браузера — это указано до запуска микрофона. Живой звук в QA не записывался; lifecycle и результаты Web Speech API покрыты mock-тестами.

## ИИ-подключение

Клиентский адаптер и отдельный Worker `server/fridge-assistant.ts` переведены на Gemini. Разрешена только стабильная модель `gemini-3.5-flash-lite`; произвольная модель в конфигурации отклоняется до расходования счётчиков. OpenAI upstream и платный fallback удалены. Публичный Worker развёрнут и проверен реальным запросом; клиент подключается к нему в этом выпуске. Проверка опубликованного интерфейса GitHub Pages ещё не завершена.

После входа пользователя найден существующий ключ Default Gemini Project (`gen-lang-client-0205401696`), в AI Studio подтверждён Free Tier без billing. Ключ сохранён локально в игнорируемом `.env.local` основного workspace как `GEMINI_API_KEY`, его значение не выводилось. Отдельный ранее созданный ключ OpenAI не используется и не публикуется.

Реальный разбор прошёл через сервер и через интерфейс Cookly: «Есть 6 яиц, литр молока, полкило куриного филе. Помидоров нет, сыр нужно купить.» дал только яйца 6 шт., молоко 1 л и куриное филе 0,5 кг. Исходные данные/количества не дополнялись. Это подтверждение конкретного сценария, а не гарантия качества любого текста или фиксированной квоты.

Пользователь подтвердил нулевой бюджет. Предыдущее предложение пополнить OpenAI было ошибкой и отменено. Не делать новых OpenAI-вызовов, не подключать billing, карты или платный fallback. Ранее созданный OpenAI-ключ остаётся локальным и не используется в production.

Пользователь выбрал [Gemini API Free Tier](https://ai.google.dev/gemini-api/docs/pricing). Бесплатная квота зависит от модели и конкретного проекта; не обещать фиксированное число запросов до проверки в AI Studio. Казахстан есть в списке поддерживаемых регионов, но право конкретного аккаунта на Free Tier подтверждается реальным запросом, а не только успешным `models.list`. Не подключать платный тариф, если аккаунту недоступен бесплатный. На Free Tier данные могут использоваться Google для улучшения продуктов; перед кнопкой Gemini это объясняется в интерфейсе. Обычный разбор доступен отдельной кнопкой, в том числе после ошибки ИИ.

Публичный backend работает через Sites: `https://cookly-fridge-assistant.cherrygrass1025.chatgpt.site`. Пользователь явно разрешил сохранить существующий Gemini-ключ в runtime secrets и открыть API посетителям Cookly. Секрет `GEMINI_API_KEY` подтверждён в ревизии 2; D1 binding `DB` и таблица `intake_limits` проверены. Исправленный backend `c80795b8ba069f6c53f4b4f03e0f46835bd7f1b9` успешно развёрнут: deployment `appgdep_6adfa680f36881918231474bc1ef1cc6`. Реальный HTTP-запрос без авторизации с Origin GitHub Pages вернул 200 и ожидаемые три продукта, исключив отсутствующие продукты и покупки. В этом выпуске клиент подключается через публичную переменную `VITE_FRIDGE_ASSISTANT_URL=https://cookly-fridge-assistant.cherrygrass1025.chatgpt.site/api/fridge/parse`. Опциональный `GEMINI_MODEL` может быть только `gemini-3.5-flash-lite`. Секрет никогда не передаётся в Vite/GitHub Pages.

При размещении выявлена несовместимость Cloudflare Workers с `redirect: 'error'`, которая давала мгновенный 502 до обращения к Google. Сервер использует `redirect: 'manual'` и отклоняет ответы 3xx; браузерный параметр `credentials` убран только из серверного запроса. Исправление проверено 50 тестами gateway и реальным запросом к размещённому серверу.

Ограничения сервера: 3 запроса в минуту и 20 в сутки на IP, 200 в сутки суммарно; счётчики сохраняются между инстансами. Это ограничения Cookly, а не обещание квоты Google. При отсутствии ключа или БД запрос закрывается с 503. Пользовательский текст и результат не сохраняются в БД. Google вызывается через `generateContent`, `responseMimeType: application/json`, совместимую `responseSchema`, не более 4000 выходных токенов. Неизвестные значения в ответе модели — пустые строки; число нормализуется только после проверки формата. Допустимые единицы, категории, положительное количество и границы строго проверяются локально. Частичный, заблокированный или невалидный ответ не принимается. Любой результат проходит экран подтверждения.

Новый `responseFormat` и усложнённые nullable-схемы возвращали `INVALID_ARGUMENT` в реальном API проекта, хотя простые запросы работали. Совместимая базовая схема с локальной валидацией проверена реальным успешным запросом. Не возвращать неподтверждённый формат только ради соответствия новому примеру из документации.

Общий бюджет 20 секунд охватывает чтение входного тела, БД, обращение к модели и чтение её ответа. Отменённый заранее запрос не расходует счётчики; отмена во время ожидания БД не запускает следующие операции. Ошибки доступа к бесплатному тарифу или ключу возвращают обезличенный 503 без предложения оплаты; rate limit — 429 с проверенным `Retry-After`. Автоматических повторов и перехода к другому провайдеру нет.

## Проверка

Локально проверены реальный Gemini, подтверждение трёх продуктов, их сохранение после перезагрузки, блокировка дублей без перезаписи запасов и ручной разбор после 503 ИИ. На ширине 320 px scrollWidth и clientWidth равны 305 px, горизонтальной прокрутки нет. Реальный микрофон не записывался. Размещённый публичный backend отдельно проверен HTTP-запросом; браузерная проверка новой версии GitHub Pages и CI этого выпуска ещё ожидаются. Последний полный прогон: 508 тестов; после исправления совместимости отдельно прошли 50 тестов gateway. Актуальные результаты сборки и QA — в `fridge-intake-validation.json`.

Распознавание продуктов по фото и обновление дизайна остаются следующими этапами.
