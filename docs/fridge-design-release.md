# Cookly: обновление холодильника и подбора

28 октября 2026.

- Одна лента рекомендаций: всё есть и небольшие докупки вместе; без выбора основного продукта. Разные продукты участвуют в поиске, слабые совпадения исключаются, отсутствующее мясо/рыба блокируют рецепт.
- Источник не предоставляет bulk-составы: один явный поиск проверяет до 4 запросов/8 полных составов, продолжение расширяет ту же ленту. Это ограниченная выборка, не полный поиск по 2080 составам. ИИ-токены на подбор не расходуются.
- Повторное добавление пополняет одну карточку. Список по умолчанию задаёт текущий остаток, чек прибавляет покупку; результат виден перед сохранением. Сроки и количество необязательны.
- После «Я приготовил» проверяются количества на выбранные порции. Остатки изменяются после подтверждения. Неизвестный остаток сохраняется без явного «Продукт закончился». Защита от повторного списания, устаревших данных и повторного импорта того же фото чека.
- Старые запасы мигрируют в совместимый формат v2. Домашняя коллекция убрана из главной/выдачи; старые ссылки открывают понятный экран каталога.
- Главная, холодильник, карточки и навигация оформлены в едином спокойном стиле. Ввод и вторичные настройки раскрываются по запросу.

Проверки: 582 теста/24 файла прошли; TypeScript прошёл; production Vite build прошёл (основной JS 445.27 kB). Дополнительная CI-сборка проверит точный опубликованный commit.

Ограничение: визуальный QA и browser end-to-end не завершены — CUA после сбросов несколько раз зависал при открытии локальной страницы. Мобильные правила проверены по коду, без подтверждённых скриншотов. Не утверждать, что desktop/mobile полностью проверены. Финальным QA-завершённым релизом считать после браузерной проверки.
