# Следующие этапы Cookly

Актуально на 27 октября 2026:

Обязательное ограничение: бюджет на ИИ — 0. Не предлагать пополнение OpenAI, не подключать платные тарифы, billing или платный fallback. Рассматривать только реальную бесплатную квоту; при её исчерпании сохранять существующий разбор на устройстве. Квота облачного провайдера общая на проект, а не на каждого посетителя.

1. Исправить сопоставление продуктов: общие базовые специи, строгие названия, уникальные счётчики, совпадения основных продуктов. Текущий выпуск.
2. Текстовый и голосовой ввод с проверкой перед сохранением реализованы. Gemini (`gemini-3.5-flash-lite`) работает через Free Tier без billing. По разрешению пользователя runtime secret сохранён, backend с D1 открыт посетителям через Sites, клиент подключён и проверен на GitHub Pages. Выпуск `00189b4fe3e7c87076cb6111cf47fe448c1fe71b`: 509 тестов в 20 файлах и обе сборки прошли; [публикация завершена](https://github.com/alikhan-35/cookly/actions/runs/40385396703). Реальный браузерный разбор вернул правильные три продукта, исключил отсутствующие продукты и покупки, до подтверждения запасы не изменялись. Mobile 320 px без горизонтальной прокрутки; консоль без ошибок и предупреждений. Подробности — `docs/fridge-intake.md`.
3. Распознавание продуктов по фото с подтверждением результата пользователем.
4. Дизайн сайта и удобство сценариев на телефоне.

Полное сопоставление по всему большому каталогу требует индекса состава. Сейчас API проверяется небольшими группами из-за квоты источника. Следующий технический шаг — согласованная выгрузка/серверный индекс состава, а не массовая загрузка из браузера каждого посетителя. ИИ сам по себе эту проблему не решает.
