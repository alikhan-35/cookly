# Следующие этапы Cookly

Согласовано 26 октября 2026:

1. Исправить сопоставление продуктов: общие базовые специи, строгие названия, уникальные счётчики, совпадения основных продуктов. Текущий выпуск.
2. Текстовый и голосовой ввод с проверкой перед сохранением реализованы. Серверный ИИ-адаптер подготовлен, но не активирован: нужна успешная выдача ключа и развёртывание API. Подробности — `docs/fridge-intake.md`.
3. Распознавание продуктов по фото с подтверждением результата пользователем.
4. Дизайн сайта и удобство сценариев на телефоне.

Полное сопоставление по всему большому каталогу требует индекса состава. Сейчас API проверяется небольшими группами из-за квоты источника. Следующий технический шаг — согласованная выгрузка/серверный индекс состава, а не массовая загрузка из браузера каждого посетителя. ИИ сам по себе эту проблему не решает.
